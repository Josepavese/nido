Nido 4.10.5 — APT and DNF repositories

Packages for the Nido local VM manager. QEMU is a host prerequisite; run nido doctor after installing.

Debian / Ubuntu (APT)

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSL https://josepavese.github.io/nido/nido-archive-keyring.asc -o /etc/apt/keyrings/nido.asc
echo "deb [signed-by=/etc/apt/keyrings/nido.asc] https://josepavese.github.io/nido/apt/ stable main" | sudo tee /etc/apt/sources.list.d/nido.list
sudo apt-get update
sudo apt-get install nido

Fedora / RHEL (DNF)

sudo curl -fsSL https://josepavese.github.io/nido/rpm/nido.repo -o /etc/yum.repos.d/nido.repo
sudo dnf install nido

The repositories are signed with the Nido package archive key (fingerprint DBB87CB63A94ABA50B33C7B919C6A95C9D280B64, expires 2029-10-24); the public keyring is served as /nido-archive-keyring.asc.
