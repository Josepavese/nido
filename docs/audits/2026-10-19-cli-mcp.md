## v4.5.29 resolution

All seven issues are closed with executable CLI/MCP regressions in
`tests/cli_mcp_safety.py`, also run by Linux VM CI. Set `NIDO_TEST_BINARY` to an
absolute candidate/release binary path and `NIDO_TEST_STORAGE` to a temporary
filesystem with sufficient space. `NIDO_TEST_EVIDENCE` optionally retains JSON
proof outside the disposable fixtures. Every scenario gets private PID/network
namespaces, a hidden user home and synthetic application state; cleanup removes
only the test-owned root. Bubblewrap and native QEMU tools are required.

The v4.5.28 artifact fails all eight original defect scenarios; v4.5.29 passes
ten scenarios, including invalid-chain preservation controls. Full Go tests,
release lint and local validator (48 PASS, 0 FAIL, 3 expected SKIP) also pass.
The skips cover optional GUI, self-update and protected in-use cache removal.
The original audit evidence remains historical; release qualification evidence
is retained separately on Data. Cross-platform CI verifies builds/unit tests;
native VM qualification was performed on Linux.
